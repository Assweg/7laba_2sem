# Калькулятор выражений и цепочки чисел

![Стек](https://img.shields.io/badge/C%2B%2B-334155?style=flat-square) ![Семестр](https://img.shields.io/badge/семестр-2-0f766e?style=flat-square) ![Статус](https://img.shields.io/badge/статус-%D0%A3%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82-64748b?style=flat-square)

Лабораторная №7: рекурсивный разбор арифметических выражений и поиск цепочки чисел с помощью перебора.

## Две самостоятельные программы

| Файл | Задача |
|---|---|
| [Calculator.cpp](Calculator.cpp) | Разбор выражений со сложением, вычитанием, скобками и пробелами |
| [SortedArray.cpp](SortedArray.cpp) | Поиск цепочки: последняя цифра предыдущего числа равна первой цифре следующего |

## Сборка и запуск

```bash
c++ -std=c++17 Calculator.cpp -o calculator
./calculator

c++ -std=c++17 SortedArray.cpp -o number_chain
./number_chain
```

## Темы работы

Рекурсия, разбор выражений, работа с цифрами числа и поиск с возвратом.
